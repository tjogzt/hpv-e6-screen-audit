# Data provenance

Every external dataset used in this archive, with its source, access date,
query/filters, and how it maps to files in this repository. Access dates that
were not logged at fetch time are marked "not recorded" rather than guessed.

## 1. HPV E6 sequence dataset (Part A)

| Item | Value |
|---|---|
| Source (primary) | UniProt protein search API |
| Access date | 2025-09 (exact day not recorded; logged in the original fetch run) |
| Records | 844 UniProt HPV E6 records |
| Secondary source | NCBI Protein |
| Records | 34 additional records |
| Combined | 878 records, 45 HPV types |
| Archived copy | `data/partA/10_extended_real_HPV_E6_dataset.csv` (English-named copy; original Chinese filename `data/partA/10_扩展真实HPV_E6数据集.csv` preserved alongside — see `FILENAME_MAP.md`) |

Derived analysis artefacts (rebuilt from this dataset by the archived scripts,
all in `results/`): `01_canonical_index.csv` (canonical index with duplicate
and low-quality flags), `02_ml_taxonomy_audit.csv` (taxonomy cleaning),
clade/type-group tables, and the selection-free dual-zinc conservation scan
`47_selection_free_zinc_scan.csv`.

**Honest disclosure:** the exact UniProt/NCBI query strings for the *sequence*
fetch were not retained in the archive; the fetch predated the audit trail
discipline introduced later. The dataset itself is archived in full, so every
downstream number is reproducible from the CSV, but re-fetching the identical
snapshot from UniProt is not guaranteed.

## 2. Receptor structure (Part B)

| Item | Value |
|---|---|
| PDB entry | 4GIZ (HPV16 E6 / E6AP / p53 core complex; Zanier et al. 2013) |
| Chain used | C (HPV16 E6 construct) |
| DBREF mapping | PDB 4GIZ chain C residues 2–143 ↔ UniProt P03126 (HPV16 E6) residues 9–150, i.e. a constant offset of +7 |
| E6AP peptide | chain B-derived LxxLL peptide = UniProt UBE3A residues 403–414 |
| Construct truncation | the PDB construct ends at PDB residue 143 = UniProt 150, i.e. the C-terminal Leu151 of the PDZ-binding motif is absent |
| Archived templates | `templates/rec_clean.pdb` (cleaned receptor), `templates/rec_cym.pdb` (8 coordinating CYS→CYM, 48 atoms), `templates/zn1_chainC.pdb` / `templates/zn2_chainC.pdb` (zinc ions as chain C residues 144/145), `templates/ZN.mol2`, `templates/peptide_LxxLL.pdb` |

Zinc coordination: ZN1 (PDB residue 144) at UNP positions 103/106/136/139,
ZN2 (PDB residue 145) at UNP positions 30/33/63/66. The bonded ZAFF/CYM
parameters are archived as `templates/zaff_reconstructed.frcmod` (machine-
readable reconstruction extracted from `code/24_zn_model_test.py`, with the
reconstruction nature and acceptance basis stated in the file header) and
`templates/zinc_nonbond_fallback.frcmod` (non-bonded fallback).

Mutation status of the receptor construct, cross-references (4XR8) and the
numbering-convention machinery are documented in the manuscript §2.5 and
implemented in `code/29_define_interface_positions.py` /
`code/31_lineage_structure_v2.py` (`GIZ_TO_UNP_OFFSET = 7`).

## 3. Ligand library (Part B)

| Item | Value |
|---|---|
| Source | ChEMBL web API (`molecule/search` endpoint) |
| Access date | 2025-10-02 |
| ChEMBL release | **not recorded at access time** |
| Query strings (20) | antiviral, antineoplastic, oncology, antiinfective, HPV, papillomavirus, cancer, tumor, neoplasm, chemotherapy, oncolytic, antitumor, antineoplastic agents, virus inhibitor, viral, DNA virus, E6, p53, PDZ |
| Processing | canonical-SMILES de-duplication → Lipinski + Veber filters → Morgan fingerprint (radius 2, 2048-bit) greedy diversity selection at Tanimoto < 0.8 |
| Result | 74-compound library |
| Archived copy | `ligands/01_candidate_ligand_library.csv` |
| Fetch script | `docking/02_fetch_ligand_library.py` (query list re-extractable from source) |

**MD candidate subset (14 compounds):** the first 14 entries of the library
CSV in file order (positional truncation, not a property-based selection).
The decisive evidence is `docking/docking_progress.json` (fetched
2025-10-07; its first ten ligand IDs match library rows 0–9 exactly) plus
the fact that Vina inputs/outputs survive only for these 14
(`docking/4GIZ_poses/`); the full provenance table is
`ligands/49_candidate_provenance_table.csv`, regenerated by
`code/49_candidate_provenance.py` with `selection_rule` recorded explicitly.
See manuscript §2.6 and §4 (scope caveat) for the honest framing.

**Cross-receptor control (not pooled):** docking of the same 14 candidates
against the second crystal receptor 4XR8 is archived in
`docking/4XR8_poses/` (54 files). 4XR8 was **excluded** from the reported
screen (construct/mutation-state reasons, manuscript §2.5 and §4); the poses
are archived so the exclusion decision is auditable.

## 5. External classifications (Part A)

- IARC HPV type risk classifications: verified against IARC Monograph 100B
  and the IARC Scientific Council 60th-session report (accessed 2026-10-26;
  recorded in `results/09_iarc_risk_verification.json`).
- ICTV Papillomaviridae taxonomy (Betapapillomavirus reorganisation):
  accessed 2026-10-25, MSL release identifier not recorded; see manuscript
  ref. 2.
- Reference genotype set: Burk et al. 2013 (406 complete HPV genomes).

## 6. Controls

- **DMSO** (negative control) and **E6AP LxxLL peptide** (positive control,
  UBE3A 403–414): built from the 4GIZ templates above; no external data
  beyond the PDB entry.
