# GaMD 第一版（σ₀ = 6.0 双 boost）— 存档，不进 Figure 5 的 PMF 面板

- 9 个作业 × 104 ns（2 ns cMD + 2 ns boost 平衡 + 100 ns 生产），
  LxxLL_peptide_rep3 只跑到 ~19 ns 就用于分析（部分轨迹，仅作参考）。
- **结论：boost 过大，重加权不可用。**
  ⟨ΔV⟩ ≈ 11.3–13.2 kcal/mol，σ_ΔV ≈ 6.3–6.9 kcal/mol，β·σ ≈ 11
  （累积量展开要求 β·σ ≲ 1）。二阶累积量与指数平均给出互相矛盾的 PMF
  （20–34 vs 3–16 kcal/mol），偏置景观本身近乎平坦（0.7–2.8 kcal/mol），
  说明 20–34 kcal/mol 是重加权噪声。
- **保留价值（用户 2026-10-31 拍板：作增强采样证据）**：即便把势垒几乎抹平，
  LxxLL 阳性对照仍 3/3 全程保持接触（d_min ≤ 3.5 Å 的帧比例 = 1.000），
  而 CHEMBL848（0.817 / 0.999 / 0.642）与 CHEMBL1129（0.772 / 0.997 / 0.952）
  均有副本完全离开起始位点（RMSD 中位数 78–169 Å）。
